# Бородинский хутор — макет главной страницы

Статичная демонстрация дизайна для согласования с заказчиком.
Открывается на телефоне (мобильная версия) и на компьютере (десктопная),
на широком экране есть переключатель «Телефон / Компьютер».

Кнопки и формы не работают — это макет, а не рабочий сайт.
Поисковыми системами не индексируется (`noindex`).
