# Бородинский хутор — демо

Статический снимок сайта для показа. Собирается скриптом
`borhorse/tools/export_static.py` из живого приложения.

Что это: внешний вид готовых страниц. Формы, запись и оплата в снимке не работают —
они появятся на рабочем сайте.

Главная перенесена из согласованного макета и сверена с ним попиксельно.
Остальные страницы — рабочие заглушки, ждут своих макетов.
