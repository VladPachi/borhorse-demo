# Бородинский хутор — демо

Статический снимок сайта для показа. Собирается двумя скриптами из живого
приложения: `borhorse/tools/export_static.py` — страницы сайта,
`borhorse/tools/export_screens.py` — все экраны записи и бронирования.

Что это: внешний вид готовых страниц. Формы, запись и оплата в снимке не работают —
они появятся на рабочем сайте.

## Что смотреть

- Сайт целиком — с главной: <https://vladpachi.github.io/borhorse-demo/>
- Все экраны записи и бронирования, включая редкие состояния (мест не осталось,
  даты заняли, время удержания истекло) — <https://vladpachi.github.io/borhorse-demo/ekrany/>

Каждая страница показывает телефонный вид на узком экране и компьютерный
на широком: ширину выбирает окно, отдельных ссылок для этого не нужно.

Главная перенесена из согласованного макета и сверена с ним попиксельно.
Остальные страницы — рабочие заглушки, ждут своих макетов.
